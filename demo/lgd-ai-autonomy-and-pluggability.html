Pluggability: five layers, one switch

A skill package plugs into the LGD system through five stacked layers. Use the switch below to unmount verified-agent-identity and watch what changes — the registry row grey out and the state flip to not-AI-callable. Re-mounting requires re-passing the gate.

Layer 1

frontmatter

Machine-readable header: title, name, description, runtime deps (bins: node). Lets an AI route the skill before reading it.

Layer 2

protocol layer

Body sections 何时用 / 用法 / 流程 — when to use it, how to call it, the order of steps.

Layer 3

scripts/

Executable entry points under scripts/, each with documented CLI form and exit codes.

Layer 4

gate scan

scan-skills-ai-readiness.py — the admission gate: no S1 = PASS, any S1 = FIX_REQUIRED.

Layer 5

registry

registry/skills.md — one row per mounted skill: ID, line, AI Protocol, Executable.
